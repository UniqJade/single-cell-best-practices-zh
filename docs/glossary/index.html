术语表

接头序列
接头序列（adapter sequence）是在测序文库（library）制备时连接或引入片段末端的短合成核酸序列，可参与片段捕获、扩增和测序。以 Illumina 为例，接头参与将文库片段固定到测序流动槽（flowcell）。当测序延伸超过插入片段时，读段（Read）中可能包含接头序列；应按建库方案识别并去除，以免干扰比对和后续分析。
算法
算法（algorithm）是为解决某类问题而规定的一组明确、可执行的步骤。
注释
注释（annotation）为数据添加标签或元信息，使其具有可解释的背景。例如，基因注释描述基因的位置、功能及相关蛋白；细胞注释描述类型、状态或功能。批次、疾病条件和性别等也可作为生物学数据的注释。
AnnData
处理带注释数据矩阵的 Python 包及其核心数据结构，常用于单细胞和其他组学分析。矩阵的行对应观测，列对应特征（feature），两轴均可附带元数据。AnnData 支持切片、取子集，以及使用 H5AD、Zarr 等格式保存数据。
BAM
二进制序列比对格式（Binary Alignment/Map, BAM）是 SAM（Sequence Alignment/Map）的二进制压缩形式，可保存 Read 序列、碱基质量、比对位置等信息。与 SAM 相比，它通常更节省存储空间，并便于高效处理；文件也可以包含未比对的 Read 记录。
扩增偏差
扩增偏差（amplification bias）指核酸扩增过程中，不同序列的扩增效率不同，导致产物中的相对丰度偏离原始样本。它会影响测序定量和基因表达分析，聚合酶链反应（Polymerase Chain Reaction, PCR）就是可能产生这类偏差的环节。
Barcode
条形码（Barcode）是用于标识分子来源的短核酸标签。本书此处主要指细胞条形码（Cell Barcode）：原始数据处理时，将具有相同 Cell Barcode 的 Reads 归到同一捕获单元。还需处理序列错误、Barcode 碰撞以及一个单元捕获多个细胞等情况，不能仅凭相同标签就断定它们必然来自一个细胞。
批次效应
批次效应（batch effect）是样本制备、仪器、实验日期等技术差异引起的数据分布变化。当批次与研究条件相关时，技术差异可能混淆生物学结论。应通过实验设计、统计建模或适当的批次校正处理；批次与条件完全混杂时，不能保证用计算方法将两者可靠分离。
基准评估
基准评估（benchmark）依据预先规定的数据、任务和指标比较多种工具的表现，通常强调独立、可复现的评价。结论受评估范围限制，不能简单推广到所有数据和任务。
bulk RNA 测序
bulk RNA 测序测量多个细胞混合后的 RNA 信号，无法直接分辨各个细胞的表达。混合信号受细胞组成、每类细胞的 RNA 总量及基因表达共同影响，并不一定是各细胞表达的简单算术平均。它通常比单细胞测序成本低、操作更简便，分析也较快。
细胞
细胞（cell）是生命的基本结构与功能单位，通常由细胞膜包裹细胞质，包含蛋白质、核酸等分子。细胞可分化、分裂、改变状态并相互通讯。研究这些过程有助于理解基因表达动态、发育谱系和疾病机制。
细胞类型注释
细胞类型注释（cell type annotation）依据标记基因、分类器或参考映射，为 细胞簇 赋予相应的 细胞类型 标签。也可以在单个细胞层面注释；一个计算得到的簇不一定只包含一种细胞类型。
细胞类型
细胞类型（cell type）是具有相近形态、功能或分子表型的一类细胞。类型可以有不同的分类层级，其边界取决于研究背景与所用证据。
细胞状态
细胞状态（cell state）描述同一 细胞类型 内随细胞周期、刺激、扰动或其他因素变化的功能与分子状态，可作为类型标签之外的另一层注释。
染色质
染色质（chromatin）是 DNA 与蛋白质形成的复合体，负责在细胞核内组织和包装 DNA，并参与调控基因表达。
密码子
密码子（codon）是由三个核苷酸组成的遗传信息单位，在翻译过程中对应某种氨基酸或终止信号；起始密码子还参与确定翻译起点。
CpG
胞嘧啶–磷酸–鸟嘌呤（cytosine–phosphate–guanine, CpG）指同一条 DNA 链沿 5′→3′ 方向相邻的胞嘧啶（C）和鸟嘌呤（G），p 表示连接两者的磷酸基团，不是互补链之间的碱基配对。CpG 可成簇形成 CpG 岛，常见于启动子附近。启动子 CpG 甲基化常与转录抑制相关，但具体作用取决于基因组位置与细胞背景，不能把所有 CpG 甲基化一概解释为基因关闭。
簇
簇（cluster）是按某种相似性和算法规则分组得到的数据点集合。单细胞分析中，可用标记基因和其他证据解释簇的生物学含义，但不能只凭聚类结果认定其功能或类型，参见 细胞类型注释。
互补 DNA（cDNA）
互补 DNA（Complementary DNA, cDNA）由逆转录酶以 RNA 为模板合成。它比 RNA 稳定，常用于 RNA 测序的文库制备，使捕获的转录本能够扩增和测序。
差异基因表达（DGE）
差异基因表达（Differential Gene Expression, DGE）指不同条件下基因表达水平的差异，可反映相应的 生物化学过程。差异表达分析是统计分析，目的是在考虑实验设计与变异后识别表达发生变化的基因；它本身不是决定基因如何响应刺激的生化机制。
解复用
解复用（demultiplexing）利用序列标签区分 Reads 的来源。在本书的逐细胞处理语境中，主要依据 Barcode。
有向图
有向图（directed graph，或 digraph）由节点和带方向的边组成。每条边表示从起点到终点的关系；具体含义取决于应用，边的方向不自动代表因果。
DNA
脱氧核糖核酸（Deoxyribonucleic Acid, DNA）储存遗传信息，其中的可转录序列可作为模板生成 RNA。
Doublet
双细胞（Doublet）指同一捕获单元包含两个细胞，相关 Reads 被归到同一个 Cell Barcode，使该记录呈现混合信号。两个以上细胞的混合更一般地称为 multiplet；实际分析有时将其统称为 Doublet，但严格计数时应区分。
下游分析
下游分析（downstream analysis）泛指原始测序数据初步处理之后的分析。单细胞 RNA 测序（Single-Cell RNA Sequencing, scRNA-seq）中，可包括过滤、归一化、整合、细胞类型识别、轨迹推断及表达动态分析；这里列举的是任务，并非固定执行顺序。
驱动基因
驱动基因（driver gene）在功能上参与推动细胞状态或命运变化。标记基因描述某种类型或状态的表达特征，两类角色并不互斥。仅由表达关联或轨迹模型得到的候选驱动基因，仍需扰动等证据验证其因果作用。
dropout
漏检（dropout）指原本存在的表达信号未被观测到。同一 细胞类型 中的低表达基因可在部分细胞检出、在另一些细胞中为零。这一现象与信使 RNA（messenger RNA, mRNA）的低丰度有关，也受到 mRNA 捕获效率和测序抽样等因素影响，还可能包含真实的生物学表达差异。单细胞矩阵稀疏并不意味着所有零值都是技术性漏检，更不能把所有零值都当成待插补的缺失值。
Drop-seq
一种基于液滴的 scRNA-seq 方案，将细胞与带 Barcode 的微珠分配到纳升级水相液滴中，实现大规模转录组分析。
编辑距离
编辑距离（edit distance）衡量将一个字符串变为另一个字符串所需的最小编辑代价。常用的 Levenshtein 距离允许单字符替换、插入和删除，三种操作代价均为 1 时，距离就是所需的最少操作次数。
Embedding
嵌入（Embedding）将细胞、词语、蛋白质或基因等对象表示为数值向量，以便计算其关系并开展后续分析。表示保留哪些性质取决于构建方法和训练目标。
FASTQ
序列与质量分数文本格式（FASTQ）保存测序 Read 的序列及逐碱基质量分数。标准记录占四行：以 @ 开头的标识符、序列、以 + 开头且可附带标识信息的分隔行，以及用 ASCII 字符编码的质量分数。RNA-seq 流程可结合比对或伪比对、Barcode 识别和分子去重等步骤，将 FASTQ 转换为基因计数（Count）；FASTQ 本身不是表达矩阵。
测序流动槽
测序流动槽（flowcell）是测序平台的关键耗材。以 Illumina 合成测序为例，表面寡核苷酸捕获文库 DNA，经扩增形成簇，再通过循环检测荧光读取序列，可并行测量大量片段。不同平台的 flowcell 结构和检测机制不同，不能把簇扩增与荧光检测概括为所有平台的共同原理。
基因表达矩阵
基因表达矩阵（gene expression matrix）按细胞与基因两轴组织表达数值。scverse 通常采用“细胞×基因”，另一些工具采用“基因×细胞”；细胞由 Cell Barcode 等标识。原始 Count 矩阵记录分子数或 Read 数，处理后的表达矩阵也可以存储归一化值，应核对所在层及数据尺度。
基因集富集分析（GSEA）
基因集富集分析（Gene Set Enrichment Analysis, GSEA）评估预定义基因集合与某种表型或条件是否存在系统性关联。通常所称的 GSEA 利用排序后的全基因列表，检验某基因集是否集中在列表两端。富集结果可辅助解释功能或通路，但不直接证明整个通路被激活或存在因果作用。
汉明距离
汉明距离（Hamming distance）是两个等长字符串在对应位置上字符不同的数量，不包含插入或删除操作。常用于序列错误检测及 Barcode 校正。
插补
插补（imputation）用模型或统计方法估计未观测的数值。插补值不是新的实验测量，其可靠性依赖数据、模型及假设；不能无条件把观测零值当作缺失值替换。
inDrop
一种基于液滴的 scRNA-seq 方案，通过微流控分隔细胞并引入 Barcode，以追踪转录本的细胞来源。
文库
测序文库（sequencing library）是完成相应建库处理、可供测序的一组核酸片段。常见 DNA/cDNA 文库中的片段带有测序接头。
模态
模态（modality）指不同类型的生物学测量或信息，例如基因表达、染色质可及性、表面蛋白、免疫受体序列及空间信息。联合分析互补模态可更全面地描述细胞身份、功能与相互关系。
位点
位点（locus，复数 loci）是某个序列或遗传要素所在的位置或区域。在测序分析中，它可指 Read 或片段的候选来源，例如基因、外显子或基因间区。确定位置有助于比对和解释其基因组背景，但重复序列可能使来源不唯一。
信使 RNA（mRNA）
信使 RNA（messenger RNA, mRNA）由基因转录并经相应加工形成，可作为蛋白质翻译的模板。其编码区提供氨基酸序列信息，非翻译区等结构也参与表达调控。
标记基因
标记基因（marker gene）的表达可指示某种细胞类型、状态或生物学过程。单细胞分析常利用标记组合注释细胞；bulk 数据中的标记信号则可能反映细胞组成和表达状态。标记的特异性依赖背景，不能总凭一个基因确定细胞身份。
MuData
由 mudata Python 包提供的多模态数据容器，基于 AnnData 组织各模态的矩阵与注释，是 scverse 生态中的主要多模态数据结构。它可保存不同模态的观测对应关系，不要求所有模态的细胞与 feature 都完全一致。
muon
scverse 生态中用于多模态单细胞分析的 Python 工具包，可在 MuData 等数据结构上开展预处理、分析和可视化。
负二项分布
负二项分布（Negative Binomial Distribution, NB）是一种离散概率分布。经典定义可按独立同分布的伯努利试验，统计达到指定失败次数前的成功次数；交换成功与失败的命名，可得到另一种常用定义。单细胞 Count 建模通常用均值和离散度参数化，也可视为伽马–泊松混合，用于描述方差大于均值的情况。
PCR
聚合酶链式反应（polymerase chain reaction, PCR）通过多轮反应扩增目标核酸序列。引物是短的合成 DNA 片段，用于界定目标区域；经过反复变性、退火和 DNA 延伸，可产生大量拷贝，实际扩增效率取决于序列与反应条件。
流程
流程（pipeline）通常也称工作流（workflow），由预先规定的处理步骤及其依赖关系组成，可按顺序执行，也可包含分支和并行步骤。
泊松分布
泊松分布（Poisson distribution）是一种离散分布，用于描述固定时间或空间范围内独立事件的发生次数。其参数是该范围内的期望事件数，均值与方差相等；常见过程假设是事件按恒定平均速率独立发生。

主成分分析（PCA）
主成分分析（Principal Component Analysis, PCA）将数据线性投影到一组正交方向，并按解释方差从大到小排序。保留前若干主成分可降低维度，但最大方差不一定对应最重要的生物学差异，结果也受中心化与缩放方式影响。
启动子
启动子（promoter）是参与转录起始与调控的 DNA 区域，RNA 聚合酶及相关转录因子可直接或通过复合体与之作用。
伪时间
伪时间（pseudotime）是根据细胞间关系推断的潜在进程坐标，用于描述沿某种状态转变的相对位置。它通常不等于真实经过的时间，其方向、分支和尺度依赖数据与模型。
pseudobulk
伪 bulk（pseudobulk）通常在每个生物学样本内按细胞类型或状态分组，对原始 Count 求和，再使用适合 bulk 数据的统计方法。汇总单位应保留生物学重复，不能把同一供体的多个细胞当作独立样本。
RNA
核糖核酸（Ribonucleic Acid, RNA）通常以单链形式存在，也可形成局部双链等结构，参与遗传信息传递和表达调控。信使 RNA（mRNA）提供翻译模板；其他 RNA 可承担结构、催化或调控功能，例如 rRNA、snRNA、miRNA、siRNA 和 lncRNA。RNA 的产生、加工和降解对于理解细胞状态与疾病机制十分重要。
RNA velocity
RNA 速率（RNA velocity）结合单细胞测量的未剪接前体 mRNA 与已剪接 mRNA 信号及转录、剪接和降解的动力学假设，估计表达状态在局部的变化方向或速率。它不是简单计算二者比值；成熟 mRNA 也不必处于稳态。结果依赖模型假设与数据质量，不能直接当作对细胞未来命运的确定预测。
SAM
序列比对格式（Sequence Alignment/Map, SAM）使用制表符分隔文本字段。除可选头部外，记录行描述 Read 的比对或未比对状态，可含序列、碱基质量、位置和比对质量等字段。同一 Read 可以有多条记录，并非文件每一行都对应一个独立 Read。
Scanpy
scverse 生态中用于单细胞分析的 Python 工具包，支持预处理、降维、聚类、统计分析和可视化等任务。
scverse
维护生命科学基础单细胞计算工具的社区联盟，相关工具包括 Scanpy、muon 和 scvi-tools。参见：https://scverse.org/
测序
测序（sequencing）是确定核酸中核苷酸排列顺序的过程。不同技术可测量 DNA，或直接/间接测量 RNA。
信噪比
信噪比（Signal-to-Noise Ratio, SNR）比较目标信号与噪声的相对强度。在测序中，噪声可包括随机误差与不需要的背景信号。较高的信噪比通常有利于分辨目标信号，但它不能单独排除系统性偏差或保证结论正确。
稀疏数据
稀疏数据（sparse data）指大量条目为零、非零条目较少的数据。稀疏与缺失的含义不同，参见 稀疏数据与缺失数据的区别。单细胞基因表达矩阵中的零既可能来自未表达，也可能来自低丰度和有限捕获/测序深度，不能都解释为不存在表达。
稀疏矩阵
稀疏矩阵（sparse matrix）是适合存储 稀疏数据 的矩阵表示，通常只显式保存非零值及其位置，可节省内存并加快某些运算。未存储的条目隐式为零，不是缺失值；实际效率取决于矩阵结构与操作。
Spike-in RNA
外源参照 RNA（Spike-in RNA）是加入样本的已知序列、已知量的 RNA，用于评估技术表现或辅助归一化与定量。其用途不只限于杂交步骤；应考虑加入时点及其与内源 RNA 在处理、捕获效率上的差异。
剪接连接处
剪接连接处（splice junction）指 RNA 剪接后连接在一起的外显子边界。识别这些连接有助于分析转录本结构和剪接模式；准确剪接有助于形成相应的成熟 mRNA。
轨迹推断
轨迹推断（trajectory inference）依据细胞间相似性、方向信息及其他证据，重建可能的状态变化路径。伪时间排序是其中一种输出或步骤，二者不完全等同；推断轨迹也不一定是真实发育谱系。
唯一分子标识符（UMI）
唯一分子标识符（Unique Molecular Identifier, UMI）是在扩增前给原始分子附加的短序列标签，用于识别同一分子的扩增拷贝并辅助去重，减轻 扩增偏差。UMI 并非绝对唯一，有限序列空间可产生碰撞，测序也会引入错误；去重与纠错需要结合 Cell Barcode、基因或比对位置等信息。
非翻译区（UTR）
非翻译区（Untranslated Region, UTR）是 mRNA 中已转录但不编码蛋白质的区域，位于编码区的 5′ 端和 3′ 端，可参与翻译效率、稳定性与定位等调控。
