空间域

🧠 关键要点

空间域（spatial domain）是同时考虑基因表达相似性与空间邻近性的聚类（clustering）结果，观测单位可以是细胞或捕获点（spot）。空间域不必与细胞类型一一对应。

部分空间域识别方法还利用组织学（histology）图像，以补充表达和位置提供的信息。

本章先在 Squidpy 中组合表达近邻图（nearest-neighbor graph）与空间邻接图，再介绍采用图卷积网络（Graph Convolutional Network, GCN）的 SpaGCN。模型参数和可选标签细化应结合组织结构选择。

本章概述如何利用表达、空间位置及组织学（histology）信息识别空间域（spatial domain）。

研究动机¶

空间组学分析常希望识别数据中的 空间模式，即寻找随 空间位置变化的特征（feature）。除细胞或捕获点（spot）× 基因矩阵外，组织图像和空间坐标还提供了额外信息，可用于描述这些变化。

识别细胞类型或状态是提出生物学假设的重要起点，通常通过表达 feature 的相似性进行聚类（clustering）。常见做法是在低维表示上构建 K 近邻图（k-nearest-neighbor graph, KNN graph），再进行社区发现（community detection）。对于空间组学，还可引入坐标上的邻近关系。将表达相似性与空间邻近性共同用于聚类，就得到空间域；空间域可能包含多个细胞类型。

空间域识别方法大体可分为两类：一类结合表达数据与空间依赖关系；另一类在此基础上进一步利用组织学图像。

第一类方法包括：

  • 使用 Squidpy 识别空间域 Palla et al., 2022

  • 隐马尔可夫随机场（Hidden Markov Random Field, HMRF）Dries et al., 2021

  • BayesSpace Zhao et al., 2021

第二类方法包括：

  • SpaGCN Hu et al., 2021

  • stLearn Pham et al., 2020

本章先用 Squidpy 演示基本思路，再介绍 SpaGCN。

使用 Squidpy 识别空间域¶

先用一个教学示例说明如何组合两类邻接关系，随后介绍更完整的建模方法。

Visium 数据中，AnnData 的每行代表一个 spot。分别根据空间坐标和主成分分析（Principal Component Analysis, PCA）坐标构建邻接图，可描述 spot 的空间邻近关系和表达相似性。预计算的 PCA 坐标已保存在 adata.obsm['X_pca'] 中，因此可直接据此构建表达近邻图（nearest-neighbor graph）。

# spatial proximity graph
sq.gr.spatial_neighbors(adata)
nn_graph_space = adata.obsp["spatial_connectivities"]

使用 Squidpy 比较两种结果。其中，原始注释（cluster）只基于表达相似性。

sq.pl.spatial_scatter(adata, color=["cluster", "squidpy_domains"], wspace=0.9)

加入空间连接后，聚类结果通常更连贯，可理解为对表达聚类施加空间平滑。这是一种便于理解的示例，也有实际研究采用 Chen et al., 2022。更复杂的模型还可显式描述空间依赖关系或利用图像信息。

SpaGCN¶

第二种方法是 SpaGCN Hu et al., 2021。它采用图卷积网络（Graph Convolutional Network, GCN），联合分析表达、位置与组织学信息。位置及图像信息用于构建 spot 间的距离和连接权重，表达数据则作为节点输入，经图卷积聚合邻域信息后识别空间域。

先导入 SpaGCN 及其他所需软件包：

import numpy as np
import requests
import SpaGCN as spg
from PIL import Image

这里从 10x Genomics 网站读取高分辨率 TIFF 组织图像，作为 SpaGCN 的额外输入。坐标和图像必须对应同一切片并使用一致的尺度。SpaGCN 也支持不使用组织学信息的分析。

    )
)

构建结合空间位置与组织学信息的图¶

下面分别提取捕获阵列坐标和图像像素坐标。阵列行列通常存放在 adata.obs["array_row"] 和 adata.obs["array_col"]，像素坐标则存放在 adata.obsm["spatial"]。

# Set coordinates
x_array = adata.obs["array_row"].tolist()
y_array = adata.obs["array_col"].tolist()
x_pixel = (adata.obsm["spatial"][:, 0]).tolist()
y_pixel = adata.obsm["spatial"][:, 1].tolist()

首先由空间坐标和图像信息计算 spot 间的距离矩阵，再通过距离构造图权重。这一步尚未使用表达矩阵；表达信息在后续模型训练时输入。函数接收坐标、图像及两个参数：beta 和 alpha。

  • beta 控制提取局部颜色信息的像素窗口宽度，需结合图像尺度选择；相关比例信息通常存放在 adata.uns['spatial'] 中。像素窗口不能直接等同于物理尺寸：常规 Visium 的捕获点直径约为 55 µm、中心间距约为 100 μm\mu mμm。

  • alpha 控制图像颜色信息在扩展距离中的权重。alpha=1 表示标准化后的图像颜色分量，其标准差缩放到 x、y 坐标标准差中较大的那个值。

# Calculate adjacent matrix
adj = spg.calculate_adj_matrix(
    x=x_pixel,
    y=y_pixel,
    x_pixel=x_pixel,
    y_pixel=y_pixel,
    image=img,
    beta=55,
    alpha=1,
    histology=True,
)

SpaGCN 的超参数¶

先确定特征长度尺度 lll，它控制图权重随距离衰减的速度。搜索 lll之前需要指定 ppp，即平均邻居权重之和相对于自身权重的目标贡献，而非邻居占总表达量的百分比。SpaGCN 对 Visium 给出的参考设置是 p=0.5。对于 Slide-seqV2 或 MERFISH 等更细尺度的数据，可考虑更大的邻域贡献，并根据数据调整。

p = 0.5
# Find the l value given p
l = spg.search_l(p, adj)

细化空间域标签¶

细化步骤根据每个 spot 及其近邻的标签决定是否重标记。默认六边形设置考察自身及六个最近邻；当原标签在该集合中支持不足，且另一标签具有足够多数时，才改为多数标签。它并非简单地把所有非多数标签改掉。该步骤适合预期具有清晰域边界的数据，可能抹去真实的局部异质性，因此是可选操作。

先仅根据阵列坐标计算二维距离矩阵，不使用组织学图像。

adj_2d = spg.calculate_adj_matrix(x=x_array, y=y_array, histology=False)
Calculateing adj matrix using xy only...

将二维距离矩阵与已预测的域标签一起传入细化函数。

refined_pred = spg.refine(
    sample_id=adata.obs.index.tolist(),
    pred=adata.obs["spaGCN_domains"].tolist(),
    dis=adj_2d,
)

把细化后的标签写入 adata.obs，并转换为分类类型，便于绘图。

adata.obs["refined_spaGCN_domains"] = refined_pred
adata.obs["refined_spaGCN_domains"] = adata.obs["refined_spaGCN_domains"].astype(
    "category"
)

比较细化前后的空间域。

sq.pl.spatial_scatter(adata, color=["refined_spaGCN_domains", "spaGCN_domains"])

本例中，细化减少了零散标签，使域边界更连贯。接下来可注释这些空间域，或据此寻找空间可变基因（Spatially Variable Genes, SVGs）；边界更平滑本身并不能证明结果更准确。
