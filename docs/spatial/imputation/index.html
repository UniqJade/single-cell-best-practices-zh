插补

🧠 关键要点

靶向原位技术按预设基因面板测量表达。例如，多重纠错荧光原位杂交（Multiplexed Error-Robust Fluorescence In Situ Hybridization, MERFISH）可提供较高空间分辨率，但基因覆盖受面板限制。

插补（imputation）利用单细胞 RNA 测序（Single-Cell RNA Sequencing, scRNA-seq）等参考数据预测未测量基因的空间表达，扩展的是预测覆盖范围，而非增加实测信息。

Tangram 在本章引用的基准研究中，在多项准确度指标和可扩展性上表现较好；具体效果仍取决于数据和评估设置。

共有基因的拟合检查可发现问题，但评估未测量基因的预测能力还需使用未参与训练的实测基因等独立证据。

研究动机¶

基于荧光原位杂交（Fluorescence In Situ Hybridization, FISH）的靶向原位技术，通常可达到单细胞乃至亚细胞尺度，但测量范围取决于预先设计的基因面板。例如，多重纠错荧光原位杂交（Multiplexed Error-Robust Fluorescence In Situ Hybridization, MERFISH）、单分子荧光原位杂交（single-molecule fluorescence in situ hybridization, smFISH）和 seqFISH+ 的基因通量因方案而异，不能一概限定为数百个。本章关注插补（imputation）：借助单细胞 RNA 测序（Single-Cell RNA Sequencing, scRNA-seq）参考数据，预测空间实验未测量的基因表达，以扩展基因覆盖范围。插补结果是模型预测，不是新增的原位测量。

构建跨技术映射¶

TangramBiancalani et al., 2021 可将空间测量与 scRNA-seq 或单细胞核 RNA 测序（Single-Nucleus RNA Sequencing, snRNA-seq）参考数据对齐。一项独立基准研究 Li et al., 2022 在其测试数据和评价设置下发现，Tangram 相比 gimVILopez et al., 2019 及 SpaGEAbdelaal et al., 2020 在多项准确度指标和可扩展性方面表现较好；这并不代表其在所有数据上都最优。Tangram 也可用于空间去卷积（deconvolution），本章则重点介绍如何通过共有 RNA 表达信息学习概率映射，将 MERFISH 的靶向测量扩展为参考数据覆盖的转录组表达预测。

Tangram 从两种技术的计数矩阵（Count matrix）构建映射。对于 scRNA-seq 或 snRNA-seq 参考数据，定义“细胞 × 共有基因”矩阵 SSS，其元素 SikS_{ik}Sik​ 表示表达量，细胞索引为 iii，基因索引为 kkk：

S∈R+ncells×ngenes   with   Sik>0.S \in \mathbb{R}_+^{n_{\text{cells}}\times n_{\text{genes}}} \ \ \text{ with } \ \ S_{ik}>0 \quad .S∈R+ncells​×ngenes​​   with   Sik​>0.
(1)

类似地，为空间数据构建“空间观测单元 × 共有基因”矩阵 GGG：

G∈R+nvoxels×ngenes   with   Gjk>0G \in \mathbb{R}_+^{n_{\text{voxels}}\times n_{\text{genes}}} \ \ \text{ with } \ \ G_{jk}>0G∈R+nvoxels​×ngenes​​   with   Gjk​>0
(2)

Tangram 用 体素（voxel） 泛指空间观测单元，并不一定是三维体素。对 MERFISH，它通常对应分割后单个细胞内汇总的基因测量；对传统 Visium，则对应一个捕获点（spot）。观测单元的排列顺序可以任意选择，但数据与元信息必须保持对应； ngenesn_{genes}ngenes​ 表示两种技术的共有基因数。

Tangram 还使用空间密度向量 d\textbf dd，描述各位置预期占有的细胞比例。对于 Visium，可参考组织图像分割所得的细胞数量来估计。形式化表示为：

d∈Rnvoxels   with   dj∈[0,1]   and   ∑jdj=1.\textbf{d} \in \mathbb{R}^{n_\text{voxels}} \ \ \text{ with } \ \ d_j \in [0,1] \ \ \text{ and } \ \ \sum_j d_j = 1 \quad .d∈Rnvoxels​   with   dj​∈[0,1]   and   j∑​dj​=1.
(3)

给定矩阵 SSS 和 GGG 以及密度向量 d\textbf dd，Tangram 学习映射矩阵 MMM，其中 Mij∈[0,1]M_{ij} \in [0,1]Mij​∈[0,1] 表示细胞 iii 被分配到空间单元 jjj的概率。它是软分配：每个细胞的概率质量总和为 1，即矩阵 MMM 的每一行归一化。该约束不等于细胞与位置之间的硬性一一匹配：

M∈R+ncells×nvoxels   with   ∑jnvoxelMij=1.M \in \mathbb{R}^{n_{\text{cells}}\times n_{\text{voxels}}}_+ \ \ \text{ with } \ \ \sum_{j}^{n_\text{voxel}} M_{ij}=1 \quad .M∈R+ncells​×nvoxels​​   with   j∑nvoxel​​Mij​=1.
(4)

对细胞维度求和，可得到分配到空间单元 jjj的期望细胞数。再除以 SSS中的参考细胞总数，即得到预测的空间密度：

mj=∑incellsMijncells.m_j = \sum_{i}^{n_\text{cells}} \frac{M_{ij}}{n_\text{cells}} \quad .mj​=i∑ncells​​ncells​Mij​​.
(5)

将这些部分合并，得到 Tangram 的目标函数：

L=KL[m,d]−∑kngenesdcos⁡(MTS:k,G:k)−∑jnvoxelsdcos⁡(MTSj:,Gj:),L = \mathbb{KL}[\mathbf m, \mathbf d] - \sum_{k}^{n_\text{genes}} d_{\cos}(M^TS_{:k}, G_{:k}) - \sum_{j}^{n_\text{voxels}} d_{\cos}(M^TS_{j:}, G_{j:}) \quad ,L=KL[m,d]−k∑ngenes​​dcos​(MTS:k​,G:k​)−j∑nvoxels​​dcos​(MTSj:​,Gj:​),
(6)

其中， MTSM^TSMTS 是预测的空间基因表达， KL\mathbb{KL}KL 表示 Kullback–Leibler 散度（Kullback–Leibler Divergence, KL divergence）， dcos⁡d_{\cos}dcos​ 表示余弦相似度（cosine similarity）。第一项比较预测密度 m\textbf mm 与给定密度 d\textbf dd。第二项逐基因比较空间表达模式，使基因 kkk 的预测值接近观测矩阵 GGG中的对应列。第三项逐空间单元比较预测与观测表达谱，后者取自矩阵 GGG。

扩展 MERFISH 的基因覆盖前，先确定两种技术的共有基因。原文以 ∼200\sim 200∼200 个基因为示意，并非固定要求；下方实际数据的空间面板包含 132 个基因。随后分别构建参考与空间表达矩阵 SSS 和 GGG。当每个空间单元对应一个细胞时，可选择均匀密度先验 1/nvoxels1/n_{\text{voxels}}1/nvoxels​；不过，下方代码实际采用的是基于 RNA Count 的密度先验。给定所选先验后，优化目标函数 LLL，得到概率映射 MMM。

空间表达谱 fjf_jfj​ 对应位置 jjj。一种估计方式是按照映射概率对参考表达加权求和： fj=∑iMijcif_j = \sum_i M_{ij} c_ifj​=∑i​Mij​ci​，其中 ci∈R+ngenes′c_i \in \mathbb{R}_+^{n'_\text{genes}}ci​∈R+ngenes′​​ 是参考细胞的全转录组表达谱。另一种方式是先选取该位置映射概率最大的参考细胞： i∗(j)=arg⁡max⁡iMiji^*(j) = \arg\max_i M_{ij}i∗(j)=argmaxi​Mij​，再用其表达谱作为预测值；这种硬选择与加权投影并不等价，也不保证不同位置选中不同细胞。其表达式为 fj=ci∗(j)f_j = c_{i^*(j)}fj​=ci∗(j)​。

确定参考与空间数据的共有基因¶

训练基因需要由两个数据集共同测量，并能反映细胞类型间的生物学差异。下方代码直接取两套基因名的交集，并将结果存入名为 markers 的变量；它没有执行标记基因（marker gene）筛选。随后调用 Tangram 的预处理函数对齐训练基因。

markers = list(set.intersection(set(adata_sc.var_names), set(adata_st.var_names)))
len(markers)

tg.pp_adatas 执行以下操作：

  • 依据 genes 参数给出的基因列表，计算单细胞与空间数据的共有基因

  • 将训练基因集合以 'training_genes' 为键保存到两个 AnnData 对象的 .uns 中

  • 确保两套数据的基因排列顺序一致

  • 默认将基因名转为小写以减少大小写差异；如需关闭该行为，设置 gene_to_lowercase = False。

计算单细胞到空间位置的映射¶

指定训练基因后，调用 Tangram 的 map_cells_to_space 构建参考细胞到空间位置的映射。它支持 mode='cells' 和 mode='clusters'两种模式：前者逐细胞映射，后者先按簇平均表达，计算通常更快，也可降低跨样本的细胞级噪声，但会损失簇内差异。本例采用 cells 模式，数据较大时可使用 GPU 缩短运行时间。

ad_map = tg.map_cells_to_space(
    adata_sc,
    adata_st,
    mode="cells",
    density_prior="rna_count_based",
    num_epochs=500,
    device="cuda",  # or: cpu
)

映射矩阵的行是参考细胞，列是空间观测单元。该矩阵位于 .X 中，所属对象为 ad_map。

因此，映射对象中 .var 和 .obs 的含义如下：

  • 在 .var 中保存空间观测单元的元信息，来源为 adata_st

  • 在 .obs 中保存参考细胞的元信息，来源为 adata_sc

训练信息保存在 .uns 中；实际使用的键为字符串 train_genes_df 和 training_history。上游此处将字段写作 .uns['training_genes_df'] 和 .uns[training_history]。

插补基因表达并映射细胞标签¶

映射结果有两种主要用途。其一，将参考数据中的细胞标签投影到空间位置，结合已知分布检查生物学合理性；本例投影的是 Leiden 簇标签。其二，将参考数据中更多基因的表达投影到空间，预测原位实验未测量的基因。可预测范围受参考数据限制。

训练分数衡量空间观测与映射预测的相似程度。中间两幅图分别比较单细胞、空间数据中的基因稀疏性与得分，每个点代表一个训练基因；最后一幅图比较两种技术的稀疏性差异。本例中，空间测量的稀疏性与得分关系较强，两套数据稀疏性接近的基因往往得分更高。这是训练拟合诊断，不能仅凭相关性断定低分全由测量稀疏性造成。

Tangram 在这里使用的相似度指标是余弦相似度。

训练基因的详细结果保存在 .uns["train_genes_df"]。

接着预测更多基因的空间表达。计算时，将 ad_map 中映射矩阵的转置与 adata_sc 中的参考表达矩阵相乘。Tangram 的 project_genes 函数封装了这一操作。返回的“空间观测单元 × 基因”矩阵沿用原空间数据 adata_st 的位置对应关系，但其表达值是模型预测，可覆盖参考数据中的全部基因。

ad_ge = tg.project_genes(adata_map=ad_map, adata_sc=adata_sc)

绘制未参与训练的基因¶

还可以查看其他基因的空间预测。某个基因是否参与训练，应以对象中的 training_genes 集合为准；不能把“在部分空间位置未检测到”的训练基因，当作未参与训练的基因。下方代码展示三个基因，解释结果时需先核对其训练集合成员身份。

genes = ["rp1", "sox17", "mrpl15"]
tg.plot_genes_sc(

    adata_predicted=ad_ge[ad_ge.obs.FOV == 0],

    spot_size=50,
)

Tangram 将额外的基因特征（feature）投影到空间后，即可查看它们在各位置的估计表达。对于没有空间实测值的基因，图中模式仍需其他证据验证。

检查细胞类型相关的表达模式¶

还可检查预测表达是否保留细胞类型相关的标记基因模式。选择各群体的高表达标记，再比较缩放后的观测与预测表达。本例使用 Lu 等人报告的标记基因 Lu et al., 2021；也可通过簇间 差异表达 分析选择标记。

control_markers = [
    "tfrc",
    "e2f2",
    "abcb4",
    "myh10",
    "podxl",
    "cd34",
    "sdc3",
    "pzp",
    "hc",
    "mrvi1",
    "gnaz",
    "vwf",
    "kdr",
    "stab2",
    "flt4",
    "col4a1",
]
fig, ax = plt.subplots(1, len(control_markers), figsize=(25, 6.8), sharey=True)
for i, marker in enumerate(control_markers):
    # Retrieving measured counts
    measured = sc.get.obs_df(adata_st, [marker, "cell_type"])
    # Calculating measured expression levels
    measured["expression_level"] = (
        MinMaxScaler().fit(measured[[marker]]).transform(measured[[marker]])
    )

    # Retrieving measured counts
    predicted = sc.get.obs_df(ad_ge, [marker, "cell_type"])
    # Calculating predicted expression levels
    predicted["expression_level"] = (
        MinMaxScaler().fit(predicted[[marker]]).transform(predicted[[marker]])
    )

    sns.violinplot(
        data=pd.concat(
            [measured, predicted], keys=["measured", "predicted"], names=["sample"]
        ).reset_index(),
        y="cell_type",
        x="expression_level",
        hue="sample",
        split=True,
        ax=ax[i],
    )
    ax[i].set_title(marker)
    ax[i].set_xlabel("")
    ax[i].set_ylabel("")
    ax[i].get_legend().remove()
plt.tight_layout()
plt.show()

每个子图对应一个标记基因，展示各细胞类型中的观测与预测表达。代码分别对实测值和预测值做最小–最大缩放，将两者各自映射到 [0,1]。本例保留了若干细胞类型相关模式，但这种比较主要检查相对分布，不能证明绝对表达量准确，也不能代替未参与训练基因上的独立验证。后续分析应保留预测值与实测值的区别。
