归一化

🧠 关键要点

移位对数（shifted logarithm）、scran 和解析式皮尔逊残差（analytic Pearson residuals）等归一化（normalization）方法，对于校正单细胞 RNA 测序（Single-Cell RNA Sequencing, scRNA-seq）数据中的技术变异并改善下游分析至关重要。

研究动机¶

至此，我们已经从数据集中移除了低质量细胞、背景游离 RNA（ambient RNA） 污染和双细胞（Doublet），数据现在以计数矩阵（count matrix）的形式存在，承载于一个 numeric matrix of shape cells x genes。这些计数代表着 单细胞 RNA 测序（single-cell RNA sequencing, scRNA-seq） 实验中一个分子的捕获、逆转录（reverse transcription, RT）和 测序 过程。其中每一步都会给相同细胞的测量计数深度（count depth）带来一定的变异，因此计数数据中细胞间基因表达的差异，可能仅仅源于采样效应。这意味着数据集（以及由此得到的计数矩阵）仍然包含差异很大的方差项。分析这样的数据集往往颇具挑战，因为许多统计方法都假定数据具有均匀的方差结构。

伽马-泊松分布

理论与经验均支持采用伽马–泊松分布（gamma–Poisson distribution）对 唯一分子标识符（unique molecular identifier, UMI） 数据建模，其二次均值–方差关系为 Var⁡[Y]=μ+αμ2\operatorname{Var}[Y] = \mu + \alpha \mu^2Var[Y]=μ+αμ2，其中均值为 μ\muμ，过度离散（overdispersion）参数为 α\alphaα。当 α=0\alpha=0α=0，这就是泊松分布（Poisson distribution），而 α\alphaα 描述的是在泊松分布之上额外的方差。

归一化（normalization）旨在通过把可观测的方差缩放到指定范围，来校正数据集中由采样效应变化所带来的原始计数差异。实践中会用到多种复杂程度各异的归一化技术。

Ahlmann-Eltze 和 Huber 最近发表的一项基准研究 Ahlmann-Eltze & Huber, 2023 比较了 22 种不同的归一化算法。值得注意的是，目前仍缺乏一项同时比较归一化对各种不同下游分析任务影响的基准研究。我们建议分析人员谨慎选择归一化方法，并始终结合后续的分析任务来评估。

本章将介绍三种归一化技术：移位对数（shifted logarithm）变换、scran 归一化和解析式皮尔逊残差（analytic Pearson residuals）。移位对数有助于稳定方差，适用于后续降维（dimensionality reduction）和识别 差异表达基因。scran 经过了广泛测试，常用于 批次 校正（batch correction）任务；而解析式皮尔逊残差则非常适合用于选择具有生物学变异性的基因，以及识别稀有细胞类型。

移位对数¶

我们要介绍的第一种归一化技术是移位对数，它基于 德尔塔方法（delta method）Dorfman, 1938。delta 方法应用一个非线性函数 f(Y)f(Y)f(Y) 作用于原始计数 YYY，目的是使整个数据集上的方差更为接近。

移位对数通过以下方式来解决这一问题：

f(y)=log⁡(ys+y0)f(y) = \log\left(\frac{y}{s}+y_0\right)f(y)=log(sy​+y0​)
(1)

，其中 yyy 为原始计数， sss 为所谓的大小因子（size factor），而 y0y_0y0​ 描述一个伪计数（pseudocount）。每个细胞的大小因子都会被确定，以考虑采样效应和不同细胞大小所带来的变化。某个细胞 ccc 的大小因子可以通过下式计算：

sc=∑gygcLs_c = \frac{\sum_g y_{gc}}{L}sc​=L∑g​ygc​​
(2)

，其中 ggg 为不同基因的索引，而 LLL 描述目标总和。从数据中确定大小因子有多种不同的方法。本节我们将采用 scanpy 的默认做法，其中 LLL 为数据集中的中位数原始计数深度。许多分析模板会为目标总和（ LLL）指定固定值，例如 L=105L=10^5L=105，或 L=106L=10^6L=106 从而得到通常所说的每百万计数（counts per million, CPM）值。对初学者而言，这些固定值或许显得随意，但可能导致远高于单细胞数据中通常水平的过度离散。

过度离散

过度离散是指数据的变异程度大于模型预期。

移位对数是一种快速的归一化技术，在揭示数据集潜在结构方面优于其他方法（尤其是在随后进行主成分分析（principal component analysis, PCA）时），也有助于稳定方差，便于后续降维和识别差异表达基因。下面来看如何将这种归一化方法应用于数据集。在 scanpy 中，可以方便地通过运行 pp.normalize_total，其中 target_sum=None。我们将 inplace 参数设为 False，因为我们想在本教程中探索三种不同的归一化技术。第二步使用缩放后的计数，我们由此得到了第一个归一化的计数矩阵。

scales_counts = sc.pp.normalize_total(adata, target_sum=None, inplace=False)
# log1p transform
adata.layers["log1p_norm"] = sc.pp.log1p(scales_counts["X"], copy=True)

第二种归一化方法同样基于 delta 方法，即 scran 基于池化（pooling）的大小因子估计方法。scran 遵循与移位对数相同的原理，通过计算 f(y)=log⁡(ys+y0)f(y) = \log(\frac{y}{s}+y_0)f(y)=log(sy​+y0​)，其中 yyy 为原始计数， sss 为大小因子，而 y0y_0y0​ 描述一个伪计数。现在唯一的区别在于，scran 利用一种解卷积（deconvolution）方法，基于对细胞池中各基因的线性回归（linear regression）来估计大小因子。这种方法旨在更好地解释数据集中所有细胞之间计数深度的差异。

细胞被划分到若干池中，scran 利用对各基因的线性回归来估计基于池的大小因子。scran 在批次校正任务上经过了广泛测试，可以方便地通过相应的 R 包调用。

scran 基于池化的大小因子估计方法

scran 估计单细胞大小因子的方法是：先把细胞池化（把多个细胞的计数相加，合并成一个“伪样本”或“池”），将它们组成相互重叠的分组以降低噪声；再通过逐基因的比较（借助线性回归）为这些池计算大小因子；然后用一个去卷积步骤，从池化的估计中推断出单个细胞的大小因子。这种方法通过利用细胞之间共享的信息，改善了稀疏单细胞 RNA-seq 数据的归一化效果。

from scipy.sparse import csr_matrix
%%R
library(scran)
library(BiocParallel)

scran 需要一个粗略的聚类（clustering）输入来提升大小因子估计的性能。在本教程中，我们采用一种简单的预处理方法，以较低的分辨率对数据进行聚类，从而为大小因子估计提供输入。基本的预处理包括：假设所有大小因子都相等（按文库大小（library size）归一化为每百万计数——CPM），并对计数数据做对数变换。

解析式皮尔逊残差¶

本章介绍的第三种归一化技术是皮尔逊残差（Pearson residual）的解析近似。提出这一技术的动机在于观察到：scRNA-seq 数据中细胞间的变异，可能被生物学异质性与技术效应所混淆。该方法利用“正则化负二项回归（negative binomial regression）”的皮尔逊残差，来对数据中的技术噪声建模，并在一个广义线性模型（generalized linear model, GLM）中显式地把计数深度作为协变量（covariate）纳入。Germain et al., 2020 在一项对不同归一化技术的独立比较中表明，该方法在去除采样效应影响的同时，保留了数据集中的细胞异质性。值得注意的是，解析式皮尔逊残差不需要诸如加伪计数或对数变换之类的下游启发式步骤。此外，Lause et al., 2021 和 Klebanoff, 2023 建议把近似的解析式皮尔逊残差，作为单细胞 RNA-seq UMI 数据一种稳健而有效的归一化方法。该方法的输出是归一化后的值，可正可负。某个细胞–基因的负残差，表示相对于该基因的平均表达和该细胞的测序深度，观测到的计数比预期少；正残差则相应地表示计数更多。解析式皮尔逊残差已在 scanpy 中实现，可直接在原始计数矩阵上计算。

皮尔逊残差

皮尔逊残差是统计建模中用于评估“模型预测值与观测数据吻合程度”的一种度量。它在考虑模型下预期变异性的前提下，告诉你预测偏离了多远。

皮尔逊残差由以下公式给出：

ri=yi−μ^iV^ir_i = \frac{y_i - \hat{\mu}_i}{\sqrt{\hat{V}_i}}ri​=V^i​​yi​−μ^​i​​
(3)

其中：

  • yiy_iyi​ 为观测值

  • μ^i\hat{\mu}_iμ^​i​ 是模型对该观测的预测值

  • V^i\hat{V}_iV^i​ 是该观测的估计方差

analytic_pearson = sc.experimental.pp.normalize_pearson_residuals(adata, inplace=False)
adata.layers["analytic_pearson_residuals"] = csr_matrix(analytic_pearson["X"])
