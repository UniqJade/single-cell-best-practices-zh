致谢

我们很容易忘记，科学上许多重大进展，往往源自过去一些看似不起眼的实验。整个单细胞领域都建立在生物学和计算机科学数十年的基础研究之上。没有基础的测序技术和原始数据处理技术，我们甚至不会设想对单细胞进行测序。试想，如果没有用于预处理和可视化的基础算法，今天我们也无法对单细胞数据做无监督分析。可是，这些算法不仅需要在理论上被提出，还需要变得易于获取、可复用，服务于所有用户；这之所以可能，正是因为许多勤奋的学生投入时间开发和维护这些框架与工具。我们站在巨人的肩膀上，也很自豪能贡献一份微薄力量，帮助用户有效分析单细胞数据。

本书是单细胞社区共同努力的成果，没有许多人的帮助便无法完成。我们非常感谢所有共同作者，也为大家共同取得的成果感到自豪。各章的致谢部分列出了共同作者的详细名单。
